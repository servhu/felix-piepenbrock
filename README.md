# felix-piepenbrock.de

Statische Website von Felix Piepenbrock (SEO & SEA, Online-Marketing).

- Kein Build-Schritt: reines HTML/CSS, ausgeliefert über Cloudflare Pages.
- Schriften (Inter, SIL Open Font License) liegen lokal in `fonts/`, keine externen Dienste.
- News-Artikel liegen in `news/`. Neue Artikel: Datei kopieren, Inhalt anpassen, in `news/index.html`, auf der Startseite und in `sitemap.xml` verlinken.

## Offene Punkte vor dem Livegang

- Telefon und ggf. USt-ID eintragen (gelb markiert in `index.html` und `impressum.html`).
- Datenschutzerklärung prüfen lassen.
- Artikel in `news/` gegenlesen und den Hinweis „Entwurf“ entfernen.
